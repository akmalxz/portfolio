# 3D Isometric Bedroom Portfolio — Muhammad Akmal Hakim

An interactive 3D isometric bedroom portfolio built with React 19, TypeScript, Vite, and native CSS 3D transforms (`preserve-3d`).

## Features
- **3D Isometric Diorama Room:** Full CSS 3D room with custom desk workstation, books, window, coffee table, nightstand, bed, lighting, and ambient shadow effects.
- **Autonomous Animated Character:** 3D adult character that walks, codes at the desktop, reads by the bookshelf, sits by the coffee table, plays mobile games on the bed, and pauses by the window with a floating cloudy thought bubble.
- **Architectural Callouts & Modals:** Perimeter callouts with SVG leader lines connecting directly into detailed section modals (Key Projects, Work Experience, Technical Skills & Bio, Education, Research Publications, and Contact & References).
- **Smooth Lighting & Theme Toggle:** Seamless toggle between Daylight and Night Lamp studio color schemes without 3D flattening.
- **Zero Scroll Viewport:** Sized for 100dvh single-screen experience.

## Running Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Automated via GitHub Actions to GitHub Pages on pushes to `main`.
